ПРОСТАЯ НАСТРОЙКА VR ТАЙМЕРА
=============================

1. Создайте Canvas в сцене:
   GameObject → UI → Canvas
   В настройках Canvas выберите: Render Mode → Screen Space - Overlay

2. Создайте текст:
   Правый клик на Canvas → UI → Text - TextMeshPro
   Назовите его "TimerText"
   Поставьте большой шрифт (80-100) для VR
   Расположите текст в верхней части экрана

3. Настройте таймер:
   Создайте пустой GameObject, назовите "VRTimer"
   Add Component → VRTimer
   В поле "Timer Text" перетащите ваш TextMeshPro
   Настройте Start Time (например, 300 для 5 минут)
   Count Down = true для обратного отсчета

Готово! Таймер будет показываться на VR очках.
